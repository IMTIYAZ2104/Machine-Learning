## Featured resume project

**Face Recognition Under Different Lighting:** a Python preprocessing pipeline using Eigenfaces (PCA) and SVD, evaluated across reconstruction ranks from 5 to 800. The resume reports high-fidelity reconstructions around rank 100 and principal-component visualizations for class separability.

The repository contains reports; executable source and environment setup should not be assumed to be included. Open the PDFs to review methods and results.
